# Паук-конспектор

Один HTML-файл, который читает длинный документ и собирает из него конспект. По тексту бегает паучок: он подсвечивает найденное и тянет к нему нити паутины. Каждый пункт конспекта ведёт к месту в тексте, откуда он взят.

Не нужны ни сервер, ни ключи, ни регистрация. Текст разбирается прямо в браузере, файл никуда не отправляется.

## Как запустить

Откройте `index.html` в браузере: двойной щелчок по файлу или GitHub Pages. Сразу загрузится пример договора, и паук начнёт его читать.

Свой документ можно:
- открыть кнопкой «Открыть файл»: PDF, DOCX, TXT, MD или HTML;
- перетащить на страницу;
- вставить кнопкой «Вставить текст» или просто сочетанием Ctrl+V.

## Что находит паук

| Что | Как |
| --- | --- |
| Суммы, проценты, даты, сроки («в течение 10 рабочих дней») | шаблоны для русского и английского |
| Главные предложения, из которых состоит конспект | алгоритм TextRank: важнее те предложения, которые больше всего связаны с остальными |
| Обязанности, штрафы, оплату, риски, выводы… | словари по режимам: «Договор», «Отчёт», «Статья» (режим определяется сам) |
| Частые слова документа | частотный подсчёт без стоп-слов |

Дополнительно:
- **Поиск**: по слову находятся все подходящие предложения, и паук пробегает по ним.
- **Фильтры**: можно оставить одну категорию, например «Суммы».
- **Копирование**: кнопка «Копировать» кладёт конспект в буфер обмена.

## Ограничения

- Конспект состоит из выдержек: это предложения самого текста, пересказа нет.
- Сканы PDF без текстового слоя не распознаются.
- Для PDF и DOCX при первом открытии нужен интернет: библиотеки pdf.js и mammoth грузятся с jsDelivr. TXT, MD, HTML и вставка текста работают офлайн.
- Старый формат `.doc` не поддерживается: сохраните файл как `.docx` или PDF.

## Устройство

Весь код находится в `index.html`: разметка, стили и скрипт, разбитый на пронумерованные разделы.
1. Текст разбивается на абзацы и предложения.
2. В каждом предложении ищутся значения и слова категорий.
3. Документ отрисовывается с подсветкой.
4. Поверх него в SVG рисуется паутина, а паук идёт по найденному в порядке текста.
